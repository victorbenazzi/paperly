# Paperly

Local-first Markdown notes. Your notes live as plain `.md` files in folders you own (vaults): no accounts, no sync, no lock-in.

Built with Tauri 2, React 19 and BlockNote.

## Install

Grab the installer for your platform from the [latest release](https://github.com/victorbenazzi/paperly/releases/latest):

- **macOS Apple Silicon** → `Paperly_*_aarch64.dmg`
- **macOS Intel** → `Paperly_*_x64.dmg`
- **Windows x64** → `Paperly_*_x64-setup.exe` or `Paperly_*_x64_en-US.msi`
- **Linux x64** → `Paperly_*_amd64.deb` or `Paperly-*.x86_64.rpm`

macOS builds are signed with a stable self-signed certificate (not notarized). After dragging Paperly into `/Applications`, run once:

```bash
sudo xattr -cr /Applications/Paperly.app
```

### Auto-update

Paperly checks GitHub Releases on launch. When a new version is published, a blue **Update** pill shows up in the title bar; one click downloads, installs and relaunches. Linux deb/rpm installs don't auto-update (Tauri limitation); update through your package manager instead.

## Development

```bash
pnpm install
pnpm tauri dev
```

`pnpm dev` alone runs the UI in a plain browser against an in-memory IPC mock.

## Releasing

Releases are built by `.github/workflows/release.yml` (macOS arm64/x64, Windows, Linux) and published as a **draft** with a signed `latest.json` updater manifest.

1. Bump the version in `package.json`, `src-tauri/Cargo.toml` and `src-tauri/tauri.conf.json` (keep the three in sync).
2. Commit, then tag and push:

   ```bash
   git tag vX.Y.Z
   git push origin main vX.Y.Z
   ```

3. Wait for the workflow, review the draft release on GitHub and **publish** it. Installed apps see the update on next launch.

Required repo secrets (already set): `TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` (updater artifact signing) and `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD` (stable macOS code-signing identity, generated by `scripts/gen-signing-cert.sh`). The private material lives only in `~/.paperly-signing/`; back it up and never commit it. Regenerating the Apple cert resets macOS permission grants for every user, so don't.
