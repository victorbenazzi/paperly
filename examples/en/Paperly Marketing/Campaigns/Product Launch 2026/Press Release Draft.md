## Body (draft)

SÃO PAULO, September 15, 2026. Paperly today released version 1.0 of its Markdown workspace for macOS.

Unlike cloud notetaking tools, Paperly stores nothing on remote servers. Notes are plain Markdown files in a folder the person already owns: a Dropbox folder, an iCloud folder, a git repository, or just the Documents folder.

"People are tired of renting access to their own thoughts," said the team. "If you cancel Paperly, you keep everything. Open the same folder in any editor and keep working."

Paperly 1.0 includes a block-based editor, instant full-text search, wiki-style links between pages, and live updates when files change on disk.

Paperly is available today as a free download.
