# Brand Guidelines

## Logo

- Primary mark: the blue mascot (girl with headphones and a pencil).
- Use the transparent version on light backgrounds, the app squircle only for icons.
- Minimum size: 24 px tall. Below that, use the wordmark only.
- Clear space: keep at least half the mascot's width empty around her.

## Color

| Token | Hex | Use |
| --- | --- | --- |
| Paper | #FDFDFD | Backgrounds, the canvas |
| Ink | #1A1A1A | Body text, line art |
| Paperly Blue | #2563EB | Accent, links, the mascot |
| Soft Blue | #DBEAFE | Tints, selected states |

## Typography

- Headings: Inter, semibold, tight tracking.
- Body: Inter, regular, relaxed line height.
- Code and file paths: JetBrains Mono.

## Don'ts

- Don't put the blue mascot on a blue background.
- Don't add gradients to the logo.
- Don't use em dashes in copy; we write with commas, colons and periods.
