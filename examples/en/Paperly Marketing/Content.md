# Content

Everything we publish that is not a campaign: blog posts, social media, the newsletter.

## Pages

* [[Editorial Calendar]]: what ships when
* Blog drafts live in the `Blog` folder, one file per post

## Workflow

1. Idea goes into [[Editorial Calendar]] as a row with status `Idea`.
2. Draft is written as a page inside `Blog`, status moves to `Draft`.
3. Review against [[Voice and Tone]], status `Review`.
4. Published, status `Done`, link added to the row.

> Drafts are never deleted. Worst case they become compost for better posts.
